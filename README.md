# Dactyl
A textboard engine for the modern day
------------------------------------
## What is a textboard?

A textboard is a type of website which features text-only anonymous discussion. There are no images unlike imageboards (e.g. 4chan, 2channel, 8kun, etc.).

## What is Dactyl?

Dactyl is a textboard engine, which means people can download it and run their own textboard. It will be updated more in the future.

## What does Dactyl run?

Dactyl will use PHP and Postgres (formerly MySQL) as its stack.
